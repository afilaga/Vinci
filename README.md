# 🎭 A² (Ardor Squared) — Премиальный Портфолио-Сайт Музыкального Дуэта

> **A² (Ardor Squared)** — это концептуальный проект профессионального музыкального дуэта Полины Винчи (вокал) и Михаила Акимова (саксофон).  
> Философия дуэта: **минимализм средств, максимальная глубина выразительности**. Сайт разработан как высокотехнологичная визитная карточка для презентации репертуара, программ выступления и мгновенного бронирования событий.

---

## 💎 Особенности Проекта и Дизайна

* 🔮 **Prism WebGL Hero** — Интерактивный интерактивный 3D-эффект преломления света на главном экране на базе библиотеки OGL. Создаёт гипнотическое и технологичное первое впечатление.
* 🌌 **WebGL Ambient Aurora** — Плавные интерактивные волны Северного Сияния на чистом WebGL (`SoftAurora`), интегрированные в качестве глубокого интерактивного фона секции «About Us». Адаптируется под активную цветовую схему (мягкий неон в светлом режиме, светящийся монохром в тёмном).
* 🪵 **Угольная Тёмная Тема** — Роскошная, «дорогая» тёмная палитра на основе премиальных тонов OKLCH (`oklch(0.21 0.005 260)` / глубокий антрацит). Полностью исключает плоский чёрный цвет, заменяя его мягкими бархатистыми градиентами, создающими премиальный визуальный объём.
* 🌐 **Интернационализация (i18n)** — Собственная ультра-легкая система переключения языков (RU / EN) на базе React Context. Сохраняет выбранный язык в `localStorage` и автоматически определяет предпочтения браузера без использования тяжёлых библиотек.
* 🎛️ **Кастомный Музыкальный Плеер** — Уникальный интерактивный проигрыватель с вращающейся виниловой пластинкой и визуализатором. В тёмном и светлом режимах пластинка автоматически инвертируется для идеального считывания и контраста.
* 📐 **Модульные Интерактивные Райдеры** — Разделы Технического и Бытового райдеров, оформленные в виде структурированных списков каналов (Input List), спецификаций звукового оборудования (PA) и детальных требований к логистике и размещению.
* ⚡ **Ultra-Fast Performance** — Оптимизированная сборка, использование современных форматов изображений (`.webp`), ленивая загрузка (`lazy loading`) и эффективный рендеринг WebGL.

## 🚀 Быстрый Старт

### Требования
Убедитесь, что у вас установлен **Node.js** версии 18 или выше.

### 1. Установка зависимостей
Установите необходимые npm-пакеты:
```bash
npm install
```

### 2. Запуск в режиме разработки
Запустите локальный dev-сервер:
```bash
npm run dev
```
Сайт откроется по адресу `http://localhost:5173`.

### 3. Сборка для продакшена
Скомпилируйте оптимизированный билд проекта:
```bash
npm run build
```
Готовые статические файлы для деплоя будут сгенерированы в папке `dist/`.

## 🌐 Развёртывание (Deployment)

Проект полностью оптимизирован для мгновенного деплоя на платформу **Vercel**:
1. Подключите ваш Git-репозиторий к панели управления [Vercel](https://vercel.com).
2. Платформа автоматически распознает конфигурацию **Vite** и выполнит сборку.
3. Каждая новая публикация в ветку `main` будет автоматически компилироваться и обновлять рабочий сайт.
